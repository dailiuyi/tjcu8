# tjcu8

A five-page Vite site using Vue 3 for its shared page shell, deployed to GitHub Pages and `tjcu8.elma-gohan.xyz`.

```powershell
npm ci
npm run dev
npm run build
npm run check:dist
```

See `docs/refactoring-progress.md` for the incremental frontend learning path and `docs/vite-toolchain.md` for the current build contract.
