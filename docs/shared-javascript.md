# 全站通用 JavaScript

## 职责边界

`js/script.js` 是全站行为的组合入口，只负责导入并初始化功能；`js/logo-animation.js` 独立管理 Logo 动画的状态、计时器和事件。用 Spring 类比，前者接近应用启动配置，后者接近一个职责单一、可测试的组件，不再把可变状态暴露为全局变量。

## 交互契约

- Logo 使用原生 `button`。鼠标悬停、点击以及按钮原生的 Enter/Space 点击都会在 1000ms 后启动动画。
- 鼠标离开、失焦或按 Escape 会停止动画并复位。
- 页面缺少 Logo 或图片时，初始化函数直接返回，不影响其他脚本。
- 系统启用“减少动态效果”时不启动旋转；偏好在动画中途变化时立即停止。
- 原动画节奏保持不变：启动速度为 2，首帧为 25°，之后每帧增加 0.5（即 5°）。

## 验证

```powershell
node scripts/check-logo-animation.mjs
python scripts/check-site.py
```

行为检查覆盖元素缺失、原始节奏、鼠标、键盘、减少动态效果和事件清理。站点检查同时约束五个页面的模块入口及 Logo 按钮语义。
